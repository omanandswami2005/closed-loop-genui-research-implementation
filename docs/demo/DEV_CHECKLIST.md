# Demo extension: development checklist

Tracks the "Bring your own material" demo (decision 2026-10-23: single learner
flow + per-topic progress report). Tick a box only when the item is built AND
verified by the check named next to it. Design: [README.md](README.md).

Legend: `[x]` done and verified, `[ ]` open. "Check" says how it was verified.

## 0. Ground rules
- [x] All demo code lives in new files: `backend/closedloop_demo/`, `frontend/demo.html`, `frontend/src/demo/`, `docs/demo/`, `Dockerfile.demo`. Check: `git diff --stat main -- backend/closedloop frontend/src/App.tsx results paper` is empty.
- [x] Only existing file edited: `frontend/vite.config.ts` (adds the second page to the build). Check: `git diff --stat main`.
- [x] Existing backend tests still pass. Check: `cd backend && python -m pytest tests --ignore=tests/demo`.
- [x] Existing frontend type-check still passes. Check: `cd frontend && npx tsc -b`.

## 1. Backend: ingestion
- [x] PDF text extraction (pypdf). Check: unit test on a generated PDF.
- [x] PPTX text extraction incl. speaker notes (python-pptx). Check: unit test on a generated PPTX.
- [x] TXT / MD / pasted text. Check: unit test.
- [x] Limits and clear errors: empty file, unsupported type, scanned PDF with no text, > 15 MB. Check: unit tests.

## 2. Backend: topic and question bank (Gemini)
- [x] Gemini (Vertex AI, `gemini-3.7-flash`, JSON response schema): one outline call (2-5 topics, summary, key points) then one call per topic in parallel (12 questions, 3 per level). Check: live calls on the 3 sample documents (11 topics, 132 questions, 0 dropped, 34-57 s) and on the e2e fixture.
- [x] Pydantic validation; invalid questions dropped, topic dropped if a level is empty. Check: unit tests with broken payloads.
- [x] Cache by SHA-256 of the extracted text (memory + disk). Check: second upload returns instantly with `cached: true`.
- [x] Pre-seeded packs (generated by real Gemini from the sample documents) ship with the app. Check: `GET /api/demo/packs` lists them with no network.

## 3. Backend: learning loop on general content
- [x] `learn-ui/1` component schema: Stack, Prompt, ConceptCard, WorkedExplanation, HintAccordion, ChoiceQuestion (guided/plain/apply), BlankQuestion. Same M_I counting (interactive elements, abstraction, depth). Check: unit tests.
- [x] Deterministic planner + builder (closest admissible layout to the budget). Check: `test_plant.py`, every reachable budget/decision for every sample question within 0.05 (worst 0.049).
- [x] Gemini per-item plant writes the screen (wording, hints, explanation using the learner's interests); answer key never comes from it. Check: live sessions in Playwright; gate result shown per screen in the gate log.
- [x] Gate: schema check, question-id integrity check, budget check, deterministic fallback. Check: unit tests with corrupted output.
- [x] Reuses `BKTTracker`, `PIDGovernor`, `SurrogatePolicy` unchanged; onboarding prior sets P(L0); guess = 0.25 for multiple choice. Check: unit test.
- [x] Deterministic grading: exact option match; blanks normalised + accepted variants. Check: unit tests.

## 4. Backend: API
- [x] `POST /api/demo/learners`, `GET /api/demo/packs`, `POST /api/demo/packs` (file or text), `POST /api/demo/sessions`, `POST /api/demo/sessions/{id}/responses`, `GET /api/demo/learners/{id}/report`, `GET /api/demo/health`. Check: API tests with FastAPI TestClient.
- [x] `closedloop_demo.app` mounts the untouched research app, so `/` and `/api/sessions` behave as before. Check: API test hits both.

## 5. Frontend: demo page
- [x] Onboarding (name, grade, interests, prior knowledge). Stored in localStorage.
- [x] Material: upload (PDF/PPTX/TXT/MD) or paste, plus sample packs; progress while Gemini works; clear error + fallback.
- [x] Topic list with summaries and per-topic status.
- [x] Learn screen: renders `learn-ui/1`, telemetry bar + trace (same instruments as the research app), outcome feedback.
- [x] Progress report page (per topic: answers, mastery start to now, levels reached, missed questions with explanations). Printable.
- [x] Fixed "demo extension, not evaluated" notice; link to Research mode.
- [x] Type-check and production build pass. Check: `npm run build`.

## 6. Real end-to-end testing

- [x] Playwright: Research mode page still loads and solves an item.
- [x] Failure paths: unsupported/empty file (Playwright); Gemini unavailable -> 503 with sample-pack advice, screen fallback (backend tests with a failing fake).
